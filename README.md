# BambuHui

A Material Design 3 interface and documentation site inspired by Bambu Studio.

**Live site:** https://ding-ding-projects.github.io/BambuHui/

## Quick start

```powershell
npm run compose-site   # builds the published Pages tree into _site/
```

Open `design/index.html` directly in any browser (`file://`) for zero-setup preview.

## Repository structure

| Path | Purpose |
|---|---|
| `design/` | Complete MD3 design contract |
| `design/app/` | Interactive prototype (vanilla JS) |
| `design/site/` | Landing page modules |
| `design/design-source/` | Read-only original design |
| `design/design-system/` | Tokens, components, guidelines |
| `.github/workflows/` | CI build + Pages deploy |
